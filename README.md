## Hi, I'm Rhyvo 👋

I make **[Ferry](https://github.com/rhyvo/Ferry)**, a free Mac app that runs Windows games and apps on Apple silicon. Drop in a game and press Play: Ferry reads it, picks the best way to run it, and installs what it needs.
